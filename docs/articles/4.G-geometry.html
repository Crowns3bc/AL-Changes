For recognized monsters, distance uses the server combat bounds: the monster type's dimensions (24 by 24 when unspecified), multiplied by its size and rounded. Sprite dimensions and skin aliases do not determine monster attack range. This also applies to is_in_range and can_attack; visual sizing and movement collision bounds are unchanged.

function point_distance(a, b) { var dx = b.x - a.x; var dy = b.y - a.y; return Math.sqrt(dx * dx + dy * dy); }

function point_at_distance(a, b, units) { var angle = Math.atan2(b.y - a.y, b.x - a.x); return { x: a.x + Math.cos(angle) * units, y: a.y + Math.sin(angle) * units }; }
